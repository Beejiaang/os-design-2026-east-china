# 工程文件分区规则

日期：2026-11-16。现有 Python 导入、配置示例、schema 和原始归档路径保持稳定；文档按用途迁入子目录。

| 路径 | 归属/用途 | 允许存放 | 不放什么 |
|---|---|---|---|
| AGENTS.md、README.md、CONTRIBUTING.md | 全员入口 | 总入口和协作说明 | 大段重复协议、临时日志 |
| src/runner、src/collector | A | 系统执行、采集、清理及兼容前提 | B 的正式负载、C 的图表逻辑 |
| src/analysis、src/report | C，代码交付时建立 | 分析与离线报告代码 | 重写过的原始数据 |
| workloads/ | B | 输入生成、分组聚合、独立正确性校验 | 生成的大数据集、A 的集成探针冒充正式负载 |
| experiments/ | B | 固定实验配置、设计和复现说明 | 未标明来源的结果、临时输入 |
| tests/ | 各角色 | 契约、负载、分析和系统测试 | 不受控生产任务 |
| schemas/ | A 维护的公共接口 | 版本化机器格式 | 历史数据改版副本 |
| examples/ | 全员接入 | 小配置、集成探针、注明来源的样例 | 大规模数据或正式统计结论 |
| scripts/ | A/集成 | 环境检查、复验、格式校验等工具 | 密码、机器专属密钥 |
| docs/project/ | 共享约定 | 统一口径、阶段、分区、提交清单 | 日常试跑日志 |
| docs/contracts/ | 公共协议 | 数据/接口语义与兼容规则 | 未确认的接口草案冒充现行规范 |
| docs/implementation/ | 各模块实现说明 | 设计与测量边界 | 测试数字脱离证据 |
| docs/validation/ | 各模块验证记录 | 命令、环境、提交、结论与局限 | 无来源的成功声明 |
| docs/handoff/ | Agent 接续 | 当前状态、角色任务、交接记录 | 过期聊天全文 |
| docs/records/ | 过程资料 | AI 使用、来源和过程披露 | 私人凭据 |
| docs/history/ | 历史资料 | 旧计划、旧选题分析 | 当前协议的另一份副本 |
| evidence/ | 已核验的共享证据 | 小型归档、清单及校验值 | 无筛选的私有日志、虚拟机镜像 |
| results/ | 本机生成，Git 忽略 | 新实验完整输出，按实验独立目录保留 | 手改的成功数据 |
| work/ | 本机临时，Git 忽略 | 缓存、试跑、干净检出等 | 需要共享的唯一实现或唯一说明 |
| demo/ | C，演示交付时使用 | 演示脚本、素材清单与真实视频入口 | 假视频链接、未生成的材料声称已交付 |

正式负载和 C 模块尚待交付；目录入口不表示功能已完成。原始运行目录和证据归档不为排版而重命名内部文件；已有结果中的路径是运行当时的事实。

新增文件先选用途再选目录。公共文档重命名时同时检查 Markdown 链接、AGENTS 指令、README、PR 说明和脚本引用；历史归档保持不变。禁止为整理文件执行仓库清空、强制重置或递归删除。
