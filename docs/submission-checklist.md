### 完整工程

- [ ] 含本队源代码、适当注释、依赖与版本、构建和环境准备文件。
- [ ] 数据生成脚本与固定输入参数可用；任务输出有正确性校验。
- [ ] 示例配置对应当前实现，命令经实际运行；不把规划命令写成已可用功能。
- [ ] 包含必要测试和异常处理；没有密码、令牌、证件、个人联系方式或虚拟机镜像。
- [ ] 干净环境按 README 能完成安装与示例运行，保存系统、版本、步骤和实际输出。

### 设计、测试与同类比较

- [ ] 需求与目标用户明确，数据处理场景与系统工具贡献有关联。
- [ ] 架构、接口、数据格式、单位、关键机制及限制清楚。
- [ ] 区分不同配额的行为实验与固定条件下的版本回归比较。
- [ ] 正常/失败/超时/权限不足/指标缺失/基线不兼容/清理失败均有实测记录。
- [ ] 实验包含环境、版本、数据与参数、重复次数依据、顺序和干扰说明。
- [ ] 图表和结论可追溯到真实原始结果；模拟数据单独标注，不进入实测结论。
- [ ] 保存健康对照和已知变慢样本；披露误报、无法判断与未覆盖场景。
- [ ] 同类工具比较说明版本、场景、相同输入、复用内容和本队增量；结论有记录。
- [ ] 不将配置上限当实际算力，不承诺耗时精确倍增，不将相关证据直接当根因。
- [ ] 非实现者完成独立复现；跨机器差异单独解释，不混入同一基线。

### 过程、来源与许可

- [ ] 阶段记录、Issue/PR、提交历史与实际开发一致；没有虚构补写的完成记录。
- [ ] 更新 docs/ai-usage.md，说明 AI 辅助、人工复核与真实执行结果。
- [ ] 外部代码/文档按规则标注来源、使用目的、授权和改动；设计文档/PPT 对应说明。
- [ ] 代码采用明确且兼容依赖的开源许可；文档使用 CC BY-SA 4.0。
- [ ] 说明本队新增模块、测试、分析或适配，未把成熟组件能力写成本队原创。
