# 2026 操作系统设计赛 · 华东区域赛

2026 年操作系统设计赛华东区域赛参赛项目仓库，涵盖选题分析、技术方案、源代码、测试实验、开发文档与演示材料。

三人团队当前选择 **OS 应用开发赛道（赛道 2）**，具体项目尚未确定。当前已上传选题分析及协作资料，后续开发内容持续在本仓库维护。

## 从这里开始

1. 阅读 **[选题分析与综合评价](docs/topic-analysis.md)**：8 个候选方向、优缺点、技术难点、验证办法及推荐顺序。
2. 每人独立填写 **[队员评价表](docs/team-review.md)**，先记录个人判断，再共同讨论。
3. 在 [选题讨论 Issue](https://github.com/Beejiaang/os-design-2026-east-china/issues/1) 留下首选、备选、主要顾虑及愿意负责的部分。
4. 按 [协作说明](CONTRIBUTING.md) 提交补充材料和修改建议。

**当前结论：**优先验证“系统性能实验与回归测试”“特定系统故障诊断”“环境与服务启动诊断”。这是可行性建议，不是最终选题或获奖概率预测。EulerLens 只是故障诊断方向的一个候选名称。

## 仓库定位

- 本 GitHub 仓库是团队持续协作的主仓库，用于分享、讨论，以及后续源代码、测试、开发文档与演示材料的版本管理。
- 赛事正式提交与开发过程留痕按组委会 GitLab 要求执行；选题后尽早建立比赛仓库并同步，不能以本 GitHub 仓库代替正式提交。
- 当前只有方案和模板，**没有已验证的原型、性能提升或诊断准确率**。
- 本仓库不存放报名证件、个人联系方式、令牌、虚拟机镜像或用户提供的原始赛事 PDF。
