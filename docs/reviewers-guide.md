# 评审导读

建议先读三份：[README](../README.md) → [设计与测试报告 RC2（PDF）](../demo/delivery/设计与测试报告_RC2.pdf) → [提交清单](project/submission-checklist.md)。依次了解项目、实现与真实测试、尚缺的人员和平台条件；PDF为RC2材料，原测量版本逐项列明，旧RC1另行保留。

| 深入查看 | 用途与入口 |
|---|---|
| 规则依据 | [统一口径](project/project-contract.md)、[平台准备](project/platform-readiness.md)说明范围、赛事来源与未确认事项 |
| 实现细节 | [系统设计](implementation/system-design.md)、[完整流程](implementation/pipeline.md)、[数据协议](contracts/data-contract.md)说明执行、校验、判定和边界 |
| 验证证据 | [集成验证](validation/pipeline-validation.md)、[对照验证](validation/comparison-validation.md)、[冻结验证](validation/release-validation.md)按源码提交追溯原始归档及 SHA256 |
| 教学材料 | [两个实验](implementation/teaching-experiments.md)、[人员复验指南](validation/peer-reproduction.md)用于动手运行和记录，不代表教学效果或人工验收 |
| 协作过程 | [当前交接](handoff/agent-handoff.md)、[AI 使用](records/ai-usage.md)、[文档总索引](README.md)区分代理实测、人员贡献与阶段状态 |

代理实测通过不能替代非实现者验收、统计显著性或官方接收；提交清单中的人工事项继续保留待办。

RC2 后续实测可从[评分项与现场演示](validation/quota-evidence.md)进入，包含可直接打开的节流证据报告。
